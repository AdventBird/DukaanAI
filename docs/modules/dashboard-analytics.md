# Dashboard and analytics

Dashboard KPIs are contract placeholders until domain modules integrate. The UI deliberately shows unavailable values and states that no sales or stock values are estimated. `grossProfit` stays unavailable until historical cost snapshots exist. Implemented now: `/api/dashboard/summary` returns explicit unavailable values; `/api/dashboard/activity` reads safe audit summaries; `/api/finance/summary` returns recorded expense totals and explicit missing sales metrics; `/api/finance/expenses` lists and records expenses. `/api/analytics/sales`, `/api/analytics/products/top-selling`, `/api/analytics/inventory/health`, and `/api/analytics/procurement/summary` have contract adapters that return explicit unavailable states until their domain modules integrate.

Metric definitions: completed sales exclude drafts/cancelled transactions; net sales subtract only explicit discounts/refunds; average basket is net sales divided by completed sales; COGS uses sale-time cost snapshots; gross profit is net sales minus COGS; expenses include only explicitly recorded operating expenses. None of these values represent audited profit.
